# Patrick Fruean — Portfolio

A responsive portfolio website built from the information in the included CV.

## Preview in GitHub Codespaces

From the repository root, run:

```bash
php -S 0.0.0.0:8000 -t Website
```

Open the **Ports** tab in Codespaces, then use the forwarded port 8000 link to view the site. The original CV is available through the download buttons on the page.
